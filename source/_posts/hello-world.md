欢迎来到我的博客！这里是用 [Hexo](https://hexo.io/) 搭建的，并按照 [GitHub Pages 部署文档](https://hexo.io/zh-cn/docs/github-pages) 配置了 GitHub Actions 自动部署。

## 日常操作

### 新建文章

``` bash
$ hexo new "我的新文章"
```

### 本地预览

``` bash
$ hexo server
```

### 生成静态文件

``` bash
$ hexo generate
```

### 部署到 GitHub Pages

推送代码到 GitHub 的 `main` 分支后，GitHub Actions 会自动构建并发布到 Pages，无需手动执行 `hexo deploy`。
